# Security policy

REBEL is an early alpha. Security updates and support timelines are **not guaranteed** for pre-release versions.

Please do **not** publish security vulnerabilities or secrets in GitHub Issues. Contact CODEMAKERS LLC through the contact information at https://code-makers.com to coordinate disclosure.

REBEL is a frontend engine. Never rely on UI visibility, menu filtering or client-side guards as the only authorization enforcement: protected APIs must validate identity and permissions on the server.
