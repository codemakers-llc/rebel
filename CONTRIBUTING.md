# Contributing to REBEL

Thank you for your interest! REBEL began as an internal CODEMAKERS engine and is now being opened to community contributions.

1. Open an Issue describing a proposed bug fix or change before significant refactoring.
2. Keep the core frontend engine decoupled from backend and domain-specific logic.
3. Follow existing JavaScript conventions and run `npm test`.
4. Describe behavior changes and include relevant regression tests.
5. Send a pull request for maintainer review.

Contributors retain copyright to their contributions unless otherwise agreed. By contributing, you agree to license your contribution under the project's MIT License, and you warrant you have the right to submit it.

Code of conduct: treat contributors respectfully; harassment and discrimination are not acceptable.
